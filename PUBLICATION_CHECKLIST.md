# Code-only publication checklist

- [x] Source code and synthetic software tests only, plus supporting documentation/configuration and an unexecuted notebook.
- [x] No raw data, annotation records, empirical outputs, fitted models, images, videos or private source links.
- [x] Notebook outputs and execution counts cleared.
- [x] MIT license selected by the repository owner for the included code.
- [x] No additional rights to external data or third-party materials implied.

Before future updates, verify that the same exclusions still hold. Software tests are not scientific validation.
